Here’s the Firebase path for nexora-app, once local mode is working.

1. Create the Firebase project
Go to Firebase Console
Create a project named nexora-app (or use that project ID)
Skip Google Analytics if you don’t need it
2. Enable services
In the project:

Authentication → Sign-in method → enable Email/Password
Firestore Database → Create database (start in production mode; we deploy rules next)
Storage → Get started
3. Register the web app
Project settings → Add app → Web
Nickname: Nexora Web
Copy the config values into apps/web/.env:
VITE_DATA_SOURCE=firebase
VITE_FIREBASE_API_KEY=...
VITE_FIREBASE_AUTH_DOMAIN=nexora-app.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=nexora-app
VITE_FIREBASE_STORAGE_BUCKET=nexora-app.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=...
VITE_FIREBASE_APP_ID=...
VITE_USE_FIREBASE_EMULATORS=false
4. Install Firebase CLI and log in
npm install -g firebase-tools
firebase login
cd c:\laragon\www\nexora
firebase use nexora-app
If the project ID isn’t nexora-app, update .firebaserc to match.

5. Deploy rules + functions
cd functions
npm run build
cd ..
firebase deploy --only firestore:rules,firestore:indexes,storage,functions
6. Create the first admin
Run the web app and register a normal user
or create one in Authentication
In Firestore → users/{uid} set:
role → admin
status → active
Sign out and sign in again so the admin UI shows
7. Switch the app to Firebase
Restart the web app after updating .env:

npm run dev
Optional: emulators (safe local Firebase)
npm run firebase:emulators
Set VITE_USE_FIREBASE_EMULATORS=true while using them.

Mobile later
Register an Android/iOS app in the same nexora-app project, then put the same project config into apps/mobile env. Same Auth + Firestore as web.

Order that matters: create project → enable Auth/Firestore/Storage → fill .env → deploy rules/functions → create admin → set VITE_DATA_SOURCE=firebase.
